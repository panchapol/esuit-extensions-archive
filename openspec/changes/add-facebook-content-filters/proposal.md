# Optional Facebook content filters

Add independent settings for the five topics seen in the user's feed: sports, AI/programming, blockchain, news/public affairs, and entertainment. Also offer format/source filters for videos, photos, text-only posts, Reels, group posts, and Suggested for you. All new settings default off and operate independently of ad blocking.

Matching runs locally using English/Thai text and visible DOM metadata. Topic matching is approximate: image-only topics and unfamiliar phrasing can be missed. No remote classification, new permissions, or account changes.
