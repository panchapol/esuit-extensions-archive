# Design

Share a fixed filter registry between popup and content script; save each switch as a separate local storage key. A post matching any enabled filter is hidden, with the existing reversible outer-slot collapse. Ad counts and content counts remain separate. Recycled material posts are classified again; virtualized placeholders retain their prior match only while a matching switch remains enabled.

Classify rendered author/message text, excluding comments, controls, dialogs, and hidden nodes. English keyword boundaries prevent AI substring matches; Thai uses explicit phrases. Format matching excludes avatar/reaction images. Group and suggested matching use header links/labels. Reels are detected by an explicit heading or Reel link. Existing ad startup gate and bounded waits stay governed by ad settings only.

Popup groups independent switches under Topics, Formats, and Sources, explains that checked means hidden, and supports Chrome's extension Options entry. Verify defaults, independence, settings propagation, recycling, slot restoration, false positives, and existing ad behavior in Chromium with an installed extension and local fixtures.
